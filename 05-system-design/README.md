# System Design

This section contains the behavioural, process, and data modelling used to design the proposed Enomy-Finances system.

The design work includes:

- Use Case Diagrams
- Activity Diagrams
- Data Flow Diagrams (DFDs)
- Finite State Machines (FSM)
- Extended Finite State Machines
- Entity Relationship Diagrams (ERDs)

These models were used to represent user interactions, system processes, data movement, system states, and database relationships before implementation.
