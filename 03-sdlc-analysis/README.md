# SDLC Analysis

This section documents the Software Development Life Cycle analysis carried out for the Enomy-Finances project.

The project reviews both sequential and iterative lifecycle models, including:

- Waterfall Model
- V-Model
- Agile Model
- Spiral Model

The analysis considers:

- Advantages and disadvantages of each model
- Risk management approaches
- Suitability for the Enomy-Finances project
- Project structure and documentation requirements
- Security and reliability considerations
- Scalability and maintainability

## Selected SDLC Model

The Waterfall Model was selected for the Enomy-Finances project because the project requirements were clearly defined and the system required a structured, well-documented development approach.

The model also supports clear project milestones, detailed documentation, controlled progression between stages, and formal review of requirements, design, testing, deployment, and maintenance.
