# Wireframes

This section contains the wireframes created for the Enomy-Finances system.

The wireframes were used to plan page structure, navigation, user interactions, and the placement of important system functions before producing the final interface designs.

Wireframes were created for areas such as:

- User type selection
- Login
- Homepages
- History displays
- Reports
- Saved quotes
- User accounts
- Currency rates
- Currency transactions
- Investment quote generation
- Investment plan details
- Account registration
- Error logs
- Currency rate management

These wireframes helped translate system requirements into a clear visual structure before the detailed interface design stage.
