# Interface Designs

This section contains the detailed interface designs created for the Enomy-Finances system.

The interfaces were designed for different user roles to ensure that each type of user can access the functions relevant to their responsibilities.

The interface designs include:

- Common interfaces for all users
- Admin interfaces
- Financial Manager interfaces
- Investment Specialist interfaces
- Client interfaces

Examples of designed screens include:

- User type selection
- Login
- Role-specific homepages
- User account management
- Error log management
- Currency rate management
- Currency transaction reports
- Investment plan management
- Investment quote generation
- Saved quotes
- Transaction history

The designs were created to support usability, role-based access, clear navigation, and effective presentation of financial information.
